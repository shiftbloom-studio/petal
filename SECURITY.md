# Security policy

## Reporting a vulnerability

Please report security problems privately by email to **safety@shiftbloom.studio**, not in a public issue or pull request.

Include what you found, how to reproduce it and the impact you expect. We aim to answer within 3 working days and will keep you posted until it's fixed. If you like, we credit you in the release notes.

## Supported versions

Only the latest `main` and the hosted version at petal.shiftbloom.studio receive security fixes.
